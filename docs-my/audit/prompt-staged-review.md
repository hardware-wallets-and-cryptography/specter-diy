# Staged Changes Review

## 1. Overall Soundness Verdict & Rationale

**Verdict: Sound overall, with a few notable findings (1 Medium security-UX gap in `TransactionScreen` scroll gating, 1 Medium edge case in `embit_compat.py` / mixed-multipath derivation claims, and 2 Low edge cases in `TransactionScreen.relative_locktime_to_text` and `LWalletManager.preprocess_psbt`).**

**Rationale:**
- **Security & Robustness Improvements:** The staged changes substantially harden the firmware against several real attack classes:
  - **Change Output Validation (`src/apps/wallets/manager.py`, `src/apps/wallets/liquid/manager.py`, `src/apps/wallets/liquid/wallet.py`):** Cryptographically binds derivation claims to `out.script_pubkey` (and in Liquid, verifies that change outputs are blinded to the wallet's own blinding key and rewinds host-provided rangeproofs on outputs), bounds derivation claim count before EC derivation (`_has_too_many_claims`), caches descriptor derivations per output, and prevents unverified or multi-wallet/unknown-input outputs from being silently hidden as change.
  - **Input Amount & Multi-Wallet Warnings (`src/apps/wallets/manager.py`):** Detects missing `non_witness_utxo` on legacy/segwit v0 inputs (or `ANYONECANPAY` taproot inputs) where fees could be understated, and warns when multiple unknown inputs could originate from different wallets.
  - **Message Signing Hardening (`src/apps/signmessage/signmessage.py`, `src/gui/screens/prompt.py`):** Enforces `MAX_PATH_DEPTH = 10` and `MAX_MSG_LEN = 512`, validates printable ASCII bytes explicitly (rejecting embedded NUL/control characters to hex display), renders frame boundaries in separate trusted `lv.label` widgets (`frame_top` / `frame_bottom`), warns on non-standard derivation paths, and suppresses misleading single-key addresses on incompatible paths (e.g., `86h` / `48h`).
  - **TRNG Liveness & PIN Fault Handling (`src/rng.py`, `src/keystore/flash.py`):** Adds a fixed-point (`Q32`, avoiding single-precision float drift on STM32) liveness check (`_looks_dead`) before feeding the entropy pool or returning raw TRNG bytes (`> 64`), and catches `RNGError` in `FlashKeyStore._unlock` before PIN evaluation or flash write so a stalled hardware RNG does not brick/wipe the device.
  - **32-bit MCU `nLockTime` Handling (`src/helpers.py`, `src/gui/screens/transaction.py`):** Implements pure-integer `conv_time` to avoid MicroPython's 31-bit small-int `OverflowError` in `utime.localtime()` on timestamps past 2068-01-19.
  - **Submodule & Build Hygiene:** Bumps `f469-disco` (bringing `embit` v0.8.2 + 4 parser/signing-authorization commits) and `bootloader` (v1.0.2 key rotation), bumps `boot/main/boot.py` firmware version monotonically (`0100900099` -> `0101000699`, i.e., `1.9.0` -> `1.10.6`), pins Nix via `flake.nix`/`flake.lock` and `shell.nix`, and adds `set -eo pipefail` to `build_firmware.sh`.
- **Churn:** Aside from `boot/main/boot.py` having a full-file CRLF -> LF line-ending normalization alongside its 1-line version bump, and the inclusion of a developer helper script (`git-fixin`) in the root tree, the changes are focused and well-structured.
